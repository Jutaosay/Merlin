# Merlin 380 Shadowsocks Plugin

This project maintains binaries and packages for [fancyss_arm380](https://github.com/hq450/fancyss_history_package/tree/master/legacy/fancyss_arm380).

## Scope

- Maintain and update features for Merlin 380 platform
- Fix legacy issues in the plugin

## Supported capabilities

- xray, vless, xtls vision, reality, trojan, trojan-go, NaiveProxy, Hysteria2
- ss + v2ray plugin
- Mixed-node subscriptions
- Multiple subscription URLs (line-separated)
- Import/subscription formats: `ss://` `vless://` `trojan://` `trojan-go://` `hysteria2://`
- smartDNS, ChinaDNS-NG
- Online update

## Compatibility

The offline package is for koolshare Merlin ARM 380 only, with Linux kernel `2.6.36.4` on `armv7`.

Supported models (koolshare Merlin **380** based firmware):

- ASUS: `RT-AC56U` `RT-AC68U` `RT-AC66U-B1` `RT-AC1900P` `RT-AC87U` `RT-AC88U` `RT-AC3100` `RT-AC3200` `RT-AC5300`
- NETGEAR: `R6300V2` `R6400` `R6900` `R7000` `R8000` `R8500`
- Linksys EA: `EA6200` `EA6400` `EA6500v2` `EA6700` `EA6900`
- Huawei: `WS880`
